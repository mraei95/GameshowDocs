Privacy Policy

Transparency is fundamental to community trust. Learn exactly what data Stage Host processes, how it is protected, and our ironclad commitment to voice audio privacy.

Zero Voice Recording

We monitor voice state (Speaker vs. Audience status) to enforce game show rules. We never listen to, record, or store microphone audio.

Ephemeral In-Memory Data

Contestant button clicks and votes are temporary, held in active memory during the 15-second round, and wiped clean when the show concludes.

No Data Brokering

We do not sell, rent, or monetize personal user data to advertisers or third-party brokers. Your community data stays in your community.

SECTION 01

1. Policy Overview

This Privacy Policy describes how Stage Host ("the Bot", "we", "us", or "our") collects, processes, and protects information when you install the Bot in your Discord server, participate in a live Stage show, or interact with our services.

We are committed to full compliance with the Discord Developer Terms of Service, the Discord Developer Policy, the General Data Protection Regulation (GDPR), and the California Consumer Privacy Act (CCPA).

SECTION 02

2. Data We Collect

To operate live stage competitions, we process only the minimum data technically necessary:

Data Category Examples Purpose
Identifiers User ID, Guild (Server) ID, Channel ID Identifying stage channels, contestant rosters, and server permissions.
Public Profile Data Server Display Name, Avatar URL Displaying survivor lists and crowning the final stage champion.
Voice State Metadata suppress boolean (Speaker vs. Audience) Detecting eligible speakers at round start; moving eliminated users to audience.
Interactive Input Button click option IDs (e.g. vote_a), timestamps Calculating answers, tie-breakers, and round statistics.
Uploaded Files JSON/CSV question files uploaded via command Parsing trivia questions, choices, and explanations for events.
SECTION 03

3. Data We Explicitly Do NOT Collect

We believe in privacy by design. We explicitly avoid collecting sensitive personal data:

  • No Message Scraping: We do NOT read, store, or log general server chat messages or private direct messages (DMs).
  • No IP Addresses: User IP addresses are never transmitted to or logged by the Bot application.
  • No Real-World Personal Information: We do NOT collect real names, physical addresses, phone numbers, or email addresses.
  • No Payment Card Numbers: All billing is processed externally through Discord or Stripe; we have zero access to your payment card details.
SECTION 04

4. Stage Channel Voice & Audio Privacy

Guaranteed: Zero Voice Audio Capture Stage Host does NOT tap into, listen to, process, record, transcript, or transmit voice audio streams from any Discord voice or stage channel.

The Bot solely subscribes to Discord's GuildVoiceStates gateway event to observe metadata: specifically, whether a participant's voice state indicates they are currently a Speaker (suppress: false) or an Audience member (suppress: true). This enables the Bot to determine who is on the Stage and execute automated game elimination moves.

SECTION 05

5. How We Use Collected Information

The information we process is used strictly for:

  1. Game Show Execution: Counting votes locked in during the 15-second timer, computing correct answers, and moving eliminated players to audience status.
  2. Anti-Cheating Protection: Ensuring votes are blind and private until the question timer concludes.
  3. Host Controls: Allowing event moderators to view live rosters and utilize the [Revive Player] select menu.
  4. Rate Limit Protection: Queuing voice state updates to ensure smooth operation without API throttling.
SECTION 06

6. Data Storage & Retention Period

We operate on a minimal retention principle:

  • Contestant Votes & Round State: Stored strictly in volatile system memory (RAM). When a game concludes or when the bot restarts, all round votes and transient game data are completely purged.
  • Question Packs: Saved locally in the bot server's questions/ directory so community moderators can replay packs. Files can be deleted at any time upon request.
  • Log Records: Operational diagnostic logs containing basic command execution events are retained for up to 14 days solely for security auditing and bug troubleshooting.
SECTION 07

7. Third-Party Sharing & Disclosure

We do not sell, rent, lease, or distribute your personal information to third parties, advertisers, or data brokers.

Data is exchanged only with essential infrastructure providers necessary to operate the service:

  • Discord Inc.: Required to transmit interactions, embeds, and voice state modifications via Discord's official API.
  • Cloud Hosting Provider: Cloud servers (such as Railway or Linux VPS) that host the bot application with strict access credentials.
SECTION 08

8. User Rights & Data Erasure (GDPR / CCPA)

Under GDPR, CCPA, and Discord developer policies, you have the right to:

  • Request confirmation of any data processed concerning your user account or server.
  • Request the immediate erasure ("Right to be Forgotten") of custom uploaded question packs or server configurations.
  • Remove the Bot from your server at any time, which immediately halts all data processing for your guild.

To submit a formal data deletion or inquiry request, contact our team using the contact details below. Requests are processed within 30 days without fee.

SECTION 09

9. Security Safeguards

All communication between Stage Host and Discord occurs over secure, encrypted WebSocket (WSS) and HTTPS (TLS 1.3) protocols. Access to hosting servers is protected by cryptographic SSH keys, strict firewall rules, and token rotation safeguards.
